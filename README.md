# 🎵 Calcify - The Musical Calculator

A creative take on the classic calculator project, built with a fun, musical twist using vanilla HTML, CSS, and JavaScript.

**► View Live Demo** *(Add your GitHub Pages link here once you deploy it)*

---

## 🚀 About The Project

I wanted to build something more engaging than just an ordinary calculator. Calcify is a fully functional web-based calculator that adds a layer of fun by playing a snippet of a popular Tamil movie song every time a number button is pressed.

This project demonstrates strong foundational skills in front-end web development, including DOM manipulation, event handling, and audio integration, all while showcasing a creative approach to a common project.

---

## ✨ Key Features

* **Standard Calculator Operations:** Supports addition, subtraction, multiplication, and division.
* **Clean & Responsive Interface:** A simple and intuitive design that works on different screen sizes.
* **Unique Audio Feedback:** Each number key is linked to a memorable song, making calculations more entertaining.
* **Vanilla Stack:** Built purely with HTML, CSS, and JavaScript to showcase core web development proficiency.

---

## 🎶 The Creative Twist: Musical Keys

As a fan of Tamil cinema and music, I decided to link each number key to a song that prominently features that number.

For example:
* Pressing **`1`** plays a clip of *"One Onnu Sollanum"* from the movie *Vaaranam Aayiram*.
* Pressing **`2`** plays a clip of *"Two Two Two"* from the movie *Kaathuvaakula Rendu Kaadhal*.
* ...and so on for the other numbers!
